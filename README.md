# 🎫 幸运刮刮乐 (Scratch Lottery)

一个纯前端的刮刮乐彩票小游戏，单文件零依赖，打开 `index.html` 即可游玩，支持手机触屏。

## 🎮 玩法

- 点击「再来一张」花费 2 元购买彩票
- 按住鼠标（或手指）刮开灰色涂层
- **横、竖、斜**任意三个相同图案连成一线即中奖
- 奖金 = 图案倍率 × 2 元（💎×30、7️⃣×60，最高 ¥120）
- 刮开约 45% 后自动揭晓结果，中奖撒花 🎉
- 顶部实时统计：已刮张数、中奖次数、花费与回本

## ✨ 技术要点

- **Canvas 刮除效果**：`destination-out` 合成模式绘制圆形笔刷擦除涂层
- **刮开比例检测**：`getImageData` 抽样统计透明像素比例
- **响应式**：`devicePixelRatio` 适配高分屏，touch 事件支持移动端
- **中奖概率**：约 25% 中奖率，预先生成中奖线再随机填充其余格子

## 🚀 运行

直接双击打开 `index.html`，或：

```bash
npx serve .
```
